# MyTodo

MyTodo 是一款轻量、本地优先的 Windows 待办应用。它把当天执行、长期规划与历史回顾分开，同时让任务、计划和计划节点保持清晰一致的编辑体验。

## 功能

- “我的一天”支持今天、明天和任意未来日期；当天任务的截止日期与所选日期保持一致
- “计划”包含目标、截止日期和多个任务节点；每个节点都可设置名称、截止日期、优先级、备注以及文件、文件夹或网页链接
- “全部任务”集中展示普通任务和计划节点，未完成项优先，已完成项分隔置底并灰度显示
- “历史记录”按每页 25 天的日期格回顾当天安排、完成情况和每日记录
- 任务、计划与计划节点统一使用双击进入详情；单击只选择，避免浏览列表时误触
- 任务与计划支持右键置顶或删除；节点支持右键在此前插入或删除，并可拖动最右侧三横线自由排序
- 回收站位于设置中，支持恢复、永久删除和清空；永久删除会移除关联历史与数据库记录，但不会删除磁盘上的原文件
- 任务、计划和计划节点均自动保存；显式点击“保存任务”或“保存计划”会保存并关闭详情栏
- 任务完成时先绘制对勾动画，再移动到已完成区域
- 快速输入任务标题后按 Enter 会直接创建并停留在列表；“＋”用于新建并填写完整属性
- 任务标题优先完整换行显示，备注摘要仅使用剩余的第二行空间
- 计划采用三列独立瀑布流，新计划放入当前最短列，卡片预览全部节点并随内容增高
- 五个主视图使用统一页头高度、正文顶线和水平边距，切换页面时布局不跳动
- 自定义背景、蒙版、主题色、字体和组件尺寸
- 雾灰、Mac、清新三种完整主题；清新计划卡采用整条书脊式左边线和右侧圆角
- SQLite 本地存储、自定义备份目录和一键备份，不需要账户或网络连接
- 应用内确认框、提示框、右键菜单与工具提示统一跟随当前主题；文件和文件夹选择器保留 Windows 标准界面

## 备注与链接

备注是一块可混排的富文本区域，可同时输入说明文字、多个网页地址、文件地址和文件夹地址。

- 粘贴网页地址后会自动显示为蓝色下划线链接
- 双击链接才会打开，单击只用于放置光标或选择文字
- 选中完整的网址或本地路径后，可通过右键菜单转换为链接
- “插入文件”和“插入文件夹”只插入原始路径，不复制、不预加载，也不会在应用启动时打开原文件
- 链接前后可继续输入任意说明文字

## 自动保存

编辑任务、计划或计划节点时，输入停止约 650 毫秒后自动写入本地数据库。关闭详情栏、切换导航、点击遮罩、按 Esc 或退出应用前也会立即保存一次。

显式保存按钮仍然保留，用于需要明确确认的场景；点击后会保存并关闭当前详情栏。名称为空时不会创建无效记录。

## 操作规则

- 单击任务、计划或节点：只选择，不打开详情
- 双击任务、计划或节点：打开属性详情
- 右键任务或计划：置顶、取消置顶或删除
- 右键节点：在当前节点前插入，或将当前节点移入回收站
- 拖动节点最右侧三横线：调整节点顺序并立即保存
- 单击完成框：先播放对勾动画，再更新完成状态
- 快速输入框按 Enter：立即添加任务，不打开详情栏

## 删除与回收站

普通“删除”会把任务、计划或计划节点移入回收站。回收站入口位于左下角“设置”的“数据与备份”区域。回收站中的内容不会出现在任务列表、计划页面或历史记录中，但仍可恢复。

“永久删除”和“清空回收站”会清除关联的任务历史、节点和旧附件路径记录，并整理 SQLite 数据库空间。MyTodo 始终只保存附件地址，因此不会删除路径指向的真实文件或文件夹。

## 数据位置

默认数据目录：

```text
文档\MyTodoData\
├─ mytodo.db
├─ Backgrounds\
├─ settings.json
├─ error.log
└─ Backups\
```

升级或重新安装不会主动删除此目录。需要全新数据时，请先退出 MyTodo，再自行备份并删除 `文档\MyTodoData`。

## 安装与运行

发布页提供两种 Windows 包：

- `MyTodo-Setup.exe`：按当前用户安装，创建开始菜单入口并支持卸载
- `MyTodo-win-x86-portable.zip`：解压后直接运行 `MyTodo.exe`

安装版与免安装版使用同一程序主体，安装本身不会明显降低运行内存。当前构建使用 32 位进程，并在启动稳定、窗口进入后台或最小化后回收不可达对象和空闲 WPF 工作集。GitHub Actions 会在无背景、8K 原图首次优化和优化后重启三种场景下执行启动测试；无背景启动稳定后的工作集上限设为 50 MB。

## 技术栈

- C# / .NET Framework 4.8
- WPF
- SQLite (`Microsoft.Data.Sqlite`)
- Inno Setup
- GitHub Actions

## 本地构建

安装 .NET 10 SDK 后，在 PowerShell 中执行：

```powershell
.\build-portable.ps1
```

脚本生成免安装 ZIP；`installer.iss` 基于同一发布目录生成安装包。
