# Linux 迁移

目标平台：Ubuntu 26.04.1 x86_64。Windows v1.0.0 的标签、发行附件和主分支保持不变，迁移在 `linux-port` 分支进行。

## 当前状态

迁移开发中，尚无可供使用的 Linux 桌面发行版。不得将数据层构建产物标作完整应用。

数据层使用同一份 `Models.cs`、`DataService.cs` 和 SQLite 表结构，不维护第二套数据库实现。Windows 默认目录不变；Linux 使用 `$XDG_DATA_HOME/mytodo`，未设置时使用 `~/.local/share/mytodo`。测试数据使用独立临时目录。

## 待完成的发行条件

- 使用 Avalonia 迁移桌面界面，并核对雾灰、Mac、清新三个主题。
- 任务、计划、计划节点双击编辑及自动保存；右键操作与编辑分离。
- 节点属性、插入、拖动排序、三列瀑布流、完成动画。
- 富文本备注中链接和文字共存，双击打开，保留 Windows 的 `note_xaml` 原始数据。
- 日期规划、历史记录 25 格、设置内回收站、字体与背景设置。
- 备份导入在副本上校验，导入前备份；Windows 盘符地址提供路径重定位，不静默改写。
- 在 Ubuntu 26.04.1 的 Wayland 和 X11 环境进行桌面验收，记录启动、空闲、背景和编辑场景的内存。
- 构建自包含 linux-x64 压缩包和 deb，完成安装、升级和卸载测试；卸载不得删除用户数据。
- 新版本使用独立标签，不删除 v1.0.0，不触发旧 Windows 工作流的 `[release]` 提交逻辑。
