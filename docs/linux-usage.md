# MyTodo Linux Preview 1

本版本为 Linux 迁移预览版，不是 Windows v1.0.0 的完整等价正式版。首次使用请导入数据库副本，保留原始 Windows 数据。

## 安装与运行

目标：Ubuntu 26.04.1 x86_64。deb 包包含 .NET 运行时，无需另装 SDK：

```sh
sudo apt install ./MyTodo_1.1.0~preview.1_amd64.deb
```

安装后从应用菜单启动 MyTodo。免安装包解压后执行 `./MyTodo`，不要用 sudo 运行应用。

Linux 数据目录为 `$XDG_DATA_HOME/mytodo`，默认 `~/.local/share/mytodo`。卸载软件不会删除用户数据。

## 从 Windows 导入

在 Windows 中先备份数据，再将 `mytodo.db` 或数据库备份复制到 Linux。打开设置，选择“导入 Windows / Linux 数据库”。导入前检查完整性和表结构，在副本上验证后替换，已有数据先备份。导入不会复制附件原文件。

数据库保留原始 `note_xaml`。Linux 读取原备注中的文字及链接；编辑备注后使用纯文本与 Markdown 链接保存。Windows 富文本的字号、粗体等格式不保证往返保留。附件盘符路径不会自动改写成 Linux 地址，请在备注中更新引用。

## 操作

- 我的任务输入名称后按回车直接创建，不打开属性栏。
- 双击任务标题、计划卡片或节点文字打开编辑，修改自动保存，离开编辑时立即保存。
- 备注预览中链接为蓝色下划线，双击打开；双击非链接区域或右键“编辑备注”进入编辑。
- 文字可与多个链接共存，支持 `[名称](https://example.org)` 和绝对文件路径。编辑中选中地址后右键可设为超链接。
- 右键任务/计划置顶或删除。节点右键可编辑、插入或删除；从最右侧手柄拖至目标节点可排到目标之前。
- 回收站位于设置中。永久删除或清空前确认，恢复功能保留关联节点。
- 附件只保存地址，不复制文件，只有双击链接时调用系统打开。

## 已知差异与验证范围

本地已执行 Linux 数据测试与无显示 UI 自动保存测试；尚未在真实 Ubuntu 26.04.1 的 Wayland/X11 桌面完成全部人工验收。不将无显示测试的内存数值作为真实桌面内存。

主题目前为初步适配，尚未达到 Windows 版 Mac/清新的完整动效与视觉一致性。完成动画、富文本原位编辑体验、拖动插入提示、窗口缩放后的瀑布流重新分配仍需进一步完善。当前节点拖动以目标节点前插为准。

安装体积包含运行时，不能据此推断运行内存。遇到异常可从终端执行 `/opt/mytodo/MyTodo` 获取日志。
