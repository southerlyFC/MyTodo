MyTodo 1.0.0 免安装版
=====================

使用方法
1. 解压整个压缩包，不要直接在 ZIP 内运行。
2. 双击 MyTodo.exe。
3. 数据默认保存在“文档\MyTodoData”，升级时不要删除该目录。

自动保存
- 任务、计划和计划节点都会在编辑时自动保存。
- 关闭详情、切换页面、按 Esc 或退出应用前会立即保存。
- 点击“保存任务”或“保存计划”会保存并关闭详情栏。

备注与链接
- 备注可混排普通文字、多个网页地址、文件地址和文件夹地址。
- 网页链接显示为蓝色下划线，双击才会打开。
- 选中完整地址后，可通过右键菜单转换为链接。
- 插入文件或文件夹只保存路径，不复制、不预加载原文件。

操作
- 快速输入任务标题后按 Enter 会直接添加，不会跳转到详情。
- 单击任务、计划或节点只选择；双击才打开属性详情。
- 任务和计划可右键置顶或删除；节点可右键插入、删除。
- 拖动节点最右侧三横线可调整顺序，结果会立即保存。
- 任务标题优先完整显示，备注摘要只占用第二行剩余空间。

日期与计划
- “我的一天”可快捷选择今天、明天或其他未来日期。
- 计划节点拥有名称、截止日期、优先级和可混排链接的备注。

删除与恢复
- 普通删除会移入回收站，并立即从任务、计划和历史记录中隐藏。
- 回收站入口位于“设置”的“数据与备份”区域，可恢复、永久删除或清空。
- 永久删除会清理关联历史和路径记录，但不会删除真实文件或文件夹。

安装版和免安装版运行同一个程序主体，安装方式不会明显改变运行内存。窗口进入后台或最小化后会主动归还空闲工作集。
